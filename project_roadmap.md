# Research extension roadmap

1. **Regularization paths:** warm-start across a logarithmic grid of \(\lambda\).
2. **Group sparsity:** compare coordinate and block shrinkage on a group-LASSO model.
3. **Douglas–Rachford splitting:** solve a nonsmooth sum or a convex feasibility problem.
4. **Monotone inclusions:** construct a strongly monotone operator and measure residual decay.
5. **Numerical analysis:** estimate empirical convergence slopes across random seeds.
6. **Cross-language validation:** run Python and R on the same CSV matrix/vector.

For a research-quality extension, define a focused question, use meaningful baselines, run multiple seeds, report uncertainty, and cite relevant literature.
